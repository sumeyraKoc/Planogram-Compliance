## Shelf and Product Detection

A pipeline for shelf and product detection for shelf monitoring using Vision Language Models (VLMs).

---

### Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Set your Gemini API key:

```bash
# Windows
set GEMINI_API_KEY=your_api_key

# Linux / macOS
export GEMINI_API_KEY=your_api_key
```

---

### Usage

Run the pipeline with either an image or a video:

```bash
python launcher.py <image_or_video_path>
```

For video inputs, the sampling interval is controlled by the `SAMPLE_INTERVAL_SEC`
parameter in `detect_shelves.py`. For example, setting

```python
SAMPLE_INTERVAL_SEC = 5
```

analyzes one frame every 5 seconds of video. The default valuse is 10 seconds.

After the pipeline finishes:

- **Final visualizations** can be found in:
  ```
  final_visualizations/{IMAGE_NAME or VIDEO_NAME}
  ```
- **Intermediate results** are saved in the corresponding folders generated by each script.

## Gap and Product Detection

A pipeline for simultaneous gap (missing facing) and product detection for shelf monitoring using Vision Language Models (VLMs).

### Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Configure your API keys in the `.env` file:

```text
API_KEY_PRODUCT_DETECTION=<your_api_key_1_here>
API_KEY_GAP_DETECTION=<your_api_key_2_here>
API_KEY_OTHER_SERVICE=<your_api_key_3_here>
```

The free Gemini model provides a limited number of API requests per day. To increase throughput and enable parallel processing, the pipeline uses multiple API keys.

It is recommended to use separate API keys for **Product Detection** and **Gap Detection**. If you do not want to create three API keys, using at least two different keys for these two modules is sufficient.

---

### Usage

Run the pipeline with either an image or a video:

```bash
python launcher.py <image_or_video_path>
```

For video inputs, the sampling interval is controlled by the `SAMPLE_INTERVAL_SEC`
parameter in `detect_shelves.py`. For example, setting

```python
SAMPLE_INTERVAL_SEC = 5

analyzes one frame every 5 seconds of video. The default value is 10 seconds.

After the pipeline finishes:

  final_visualizations/{IMAGE_NAME or VIDEO_NAME}
  ```

- **Intermediate results** are saved in the corresponding folders generated by each script.
