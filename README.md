# Planogram Compliance
## Shelf and Product Detection

A pipeline for shelf and product detection to evaluate planogram compliance using Vision Language Models (VLMs).

---

### Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Set your Gemini API key:

```bash
# Windows
set GEMINI_API_KEY=your_api_key

# Linux / macOS
export GEMINI_API_KEY=your_api_key
```

---

### Usage

Run the pipeline with either an image or a video:

```bash
python launcher.py <image_or_video_path>
```

After the pipeline finishes:

- **Final visualizations** can be found in:
  ```
  final_visualizations/{IMAGE_NAME or VIDEO_NAME}
  ```
- **Intermediate results** are saved in the corresponding folders generated by each script.

#### 2. Shelf Masking

`get_masked_images.py` creates a masked image for each detected shelf in every frame. These masked images allow the Vision Language Model to focus on a single shelf at a time.

#### 3. Product Detection

`detect_products.py` performs product detection on each masked shelf image independently.

---

#### 4. Merge Detection Results

`merge_masked_detection_results.py` merges the product detections from all shelves back into the original frame.

---

#### 5. Final Visualization

`visualize_the_final_results.py` generates the final visualization containing all detected shelves and products.

### Notes

- The pipeline uses **Gemini 3.5 Flash**.
- The free tier is limited to **15 API requests per minute**.
- To avoid exceeding the rate limit, a **5-second delay** is added after each API request.
